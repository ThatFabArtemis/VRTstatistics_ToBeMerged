# VRTsensors

Physiological sensor recording for VRTstatistics: one command per sensor (BITalino, EmotiBit), an
ingest step that merges the recordings into `combined.json`, and a checker for recordings.

All documentation is in [`docs/`](../docs/README.md). Every command and option is in
[10 Command reference](../docs/10-command-reference.md); installing is in
[02 Installing](../docs/02-installing.md).
