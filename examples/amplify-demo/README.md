# AMPlify demo settings

Ready-made settings folders for recording the Sleeping Giant demo with sensors under `VRTrun`:
`config/` (two machines), `config/self/` (one machine, both sensors) and `config-single/` (one
machine that runs by itself).

Copy the folder you want somewhere of your own before editing it. What's in each folder, and the
three values you replace, are explained in
[04 Running a session](../../docs/04-running-a-session.md#the-example-settings).
